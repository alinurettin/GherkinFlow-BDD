# 🧪 GherkinFlow-BDD

> **High-Performance Streaming Gherkin BDD Compiler and Step Execution Runtime**  
> *Author:* **Ali Nurettin Demir** ([@alinurettin](https://github.com/alinurettin))  
> *Discipline:* **Behavior-Driven Development (BDD) & Specification by Example** | *Port:* `7075`

---

## 🎯 English Overview
High-performance, streaming Gherkin syntax lexer, AST parser, and step execution engine. Supports Feature, Scenario, Scenario Outline, Examples tables, Background, DocStrings, and regex/cucumber expression step definition matching with lifecycle hooks.

### Key Capabilities
- **Algorithmic Integrity:** Built natively in Node.js with zero third-party runtime bloat and sub-millisecond execution.
- **Interactive Web Console:** Dark-mode diagnostics dashboard embedded on port `7075`.
- **Developer CLI:** Native command-line interface (`gherkin-flow`) for direct CI/CD pipeline integration.
- **Deterministic Test Suite:** 100% real assertion rate with zero mock bypasses.
- **Container Ready:** Includes production `Dockerfile`, `docker-compose.yml`, and GitHub Actions workflow.
